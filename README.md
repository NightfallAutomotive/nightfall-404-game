# Nightfall 404 GBA Emulator

An experimental concept for the Nightfall Automotive custom 404 page.

Before the Nightfall Runner arcade racing game was created, the idea was to turn a missing page into something a little more interesting: a Game Boy Advance emulator experience rather than a standard 404 error.

## The idea

- Replace the usual boring 404 page with something interactive.
- Give visitors something unexpected to discover when they take a wrong turn.
- Explore a more entertaining way to handle missing pages on the Nightfall Automotive website.

## Status

**Archived concept — not currently in use.**

The emulator concept was set aside in favour of **Nightfall Runner**, a custom arcade-style driving game built for the Nightfall Automotive website.

This repository remains as a record of the original idea and how the project evolved.

*Every wrong turn has to start somewhere.*
